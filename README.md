# SafeNet - Network Inventory & Vulnerability Scanner

SafeNet is an automated network discovery and security assessment tool built for internal network monitoring. It combines network scanning, inventory reconciliation, and CVE intelligence into a single platform.

## Features
- Automated Nmap scanning with OS and service detection
- Live inventory reconciliation (Validated / Departed / Rogue / Intrusion)
- CVE checking via the NIST NVD API with local caching
- Historical vulnerability tracking per device
- Lightweight Flask web dashboard for real‑time visualisation
